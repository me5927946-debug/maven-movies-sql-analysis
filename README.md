# Maven Movies SQL Analysis

## Project Overview

SQL business analysis using the Maven Movies rental database.

The goal of this project is to analyze customer activity, movie rentals, and business performance using SQL.

## Tools

- MySQL
- MySQL Workbench
- SQL

## Current Analysis

### Customer Activity

- Total customers: 599
- Active customers: 584
- Inactive customers: 15
- Active customer percentage: 97.5%

## Business Questions

- How many customers are in the database?
- How many customers are active?
- How many customers are inactive?
- How many customers have specific names?
- How many films have different rental rates?
